# Sky Islands - Ball Runner

Videojuego de plataformas 3D desarrollado en Unity 2020.3.49f1 para la asignatura RAA de la Universidad de Oviedo.

El juego cuenta con tres niveles, recogida de monedas, obstáculos y plataformas móviles.

## Archivos del proyecto

- **Code:** código fuente, escenas y recursos del proyecto Unity.
- **[Releases](https://github.com/victooorltt/SkyIslands-BallRunner-RAA/releases/tag/Entrega):**
  - `SkyIslands.unitypackage`: paquete del proyecto Unity.
  - `EjecutableWindows.zip`: ejecutable para Windows y archivos necesarios para jugar.
